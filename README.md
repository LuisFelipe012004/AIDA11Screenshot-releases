# AIDA11 Screenshot

Instalador e atualizações do **AIDA11 Screenshot**. Este repositório contém só os arquivos de instalação; o
código-fonte é privado.

## Instalar

1. Baixe o **`AIDA11Screenshot-win-Setup.exe`** da [versão mais recente](../../releases/latest).
2. Execute o instalador. Se o Windows mostrar "O Windows protegeu o computador", clique em
   **Mais informações → Executar assim mesmo**.
3. Entre com o e-mail e a senha da sua conta.

O app se atualiza sozinho: quando sair uma versão nova, aparece **"Versão X pronta — reiniciar"** no topo da
janela.

## Conta

É necessário ter uma licença ativa. Cada licença funciona em **1 PC**; para trocar de computador ou recuperar a
senha, fale com o suporte.
